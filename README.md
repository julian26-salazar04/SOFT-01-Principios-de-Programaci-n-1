# SOFT-01-Principios-de-Programacion-1

Coleccion de archivos y practicas que vemos en clase.

## Ejercicios

- ´condicionales.py´: ejercicio que utiliza una estructura con condicionales
- ´constantes.py´: contiene algunas constantes
- ´ejercicio.py´: ejercicio en el cual tenia que agregar tres variables
- ´ejercicio2.py´: ejercicio que pide informacion y hace calculos con los mismos para mostrar informacion al usario
- ´operadores.py´: ejercicio para utilizar operadores aritmeticos
- ´practica_cine.py´: ejercicio que pide informacion acerca de entradas del cine y muestra informacion al usuario
- ´tipos_datos.py´: muestra los tipos de datos que hay en python
- ´beca_estudiantil.py´: ejercicio para averiguar si estudiante obtiene la beca estudiantil
